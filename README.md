# Libft Project

The **Libft** project is part of the **École 42** curriculum. In this project, students are required to implement a custom library (`libft`) that mimics the functionality of commonly used C standard library functions. This project aims to help students improve their understanding of low-level C programming, memory management, and data structures.

## Project Description

The **Libft** project requires you to write your own C library by implementing functions from the standard C library (`libc`). These implementations must behave the same way as the original functions but are written by you.

This library will serve as a basis for future projects, as it will be used to handle basic functionalities like string manipulation, memory allocation, file handling, and data structures.

### Key requirements:

- Implement a set of functions that replicate parts of the C standard library (e.g., `strlen`, `memcpy`, `malloc`).
- Ensure the library functions are well-tested and handle edge cases properly.
- Pay close attention to memory management and avoid memory leaks.

## Objectives

- Implement functions from the C standard library (`libc`).
- Use your custom library functions in future projects.
- Learn about low-level C programming and memory management.
- Implement and test various utility functions and data structures.

## Technologies Used

- **C**: The project is implemented in the C programming language.
- **Makefile**: For compiling and managing dependencies.
